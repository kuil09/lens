# Security reporting

Lens is a development preview; there is no published stable security-support window. Reports concerning the current development code are welcome.

Do not publicly disclose vulnerabilities, exploit details, private screen content, credentials, or sensitive diagnostic logs in issues or pull requests.

GitHub private vulnerability reporting for [kuil09/lens](https://github.com/kuil09/lens) is **not currently enabled**.

Contact the maintainer, **kuil09**, to request a private reporting channel. Any public request for a channel must contain no vulnerability details or attachments. No email address or alternative private channel is asserted here. Enabling GitHub private reporting is a separate future repository action; this documentation does not enable it. If enabled later, verify the setting and update this policy before directing reporters to that action.

Once a private channel is established, provide the affected revision/app version, macOS version, impact, and a minimal reproduction using synthetic data. Coordinate disclosure with the maintainer; no response-time or remediation-time guarantee is currently offered.

For normal permission, language, or export problems, see [troubleshooting](docs/troubleshooting.md). For data handling, see [privacy](docs/privacy.md).
