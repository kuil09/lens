# Lens 0.1.0-beta.3 — Development Preview

App 0.1.0, build 9. Requires Apple Silicon and macOS 26.4 or later.

## Download and install

- Download `Lens-0.1.0-beta.3-9-DEVELOPMENT-NOT-NOTARIZED.dmg` and its `.sha256` sidecar.
- Quit an older Lens, open the DMG, and drag **Lens** to **Applications**. The image includes the MIT license, copyright 2026 kuil09.
- The app is **Developer ID signed with hardened runtime, but not notarized**. The DMG is not a notarized distribution. Gatekeeper may block downloaded copies; do not disable security protections. Building this tag with Xcode 26.4 or later is an alternative.
- The bundle identifier stays `dev.local.lens`; language and save-folder settings are preserved. Signature continuity does not guarantee retained macOS screen-recording consent.

```sh
shasum -a 256 -c Lens-0.1.0-beta.3-9-DEVELOPMENT-NOT-NOTARIZED.dmg.sha256
```

## What's new

- Wrapped OCR lines retain paragraph context, including short final lines, while conservative grouping keeps columns, menus, lists, and table cells apart.
- Live capture, completed translations, and whole-block visibility masks are separate. Changes hide affected translations without clearing unrelated text or canceling every batch.
- Region-adaptive backoff uses 250 ms, 500 ms, 1 s, and 2 s intervals, with early quiet recovery. Capture stays live; one OCR job and one translation batch share bounded pending state. The 2 s cap is not a translation-latency guarantee.
- A separate, attached header keeps language controls, translation, capture, recording stop, settings, and the click-through toggle available while the body passes input through. Native input delivery still needs manual acceptance.
- Existing Liquid Glass UI, English/Korean/Japanese localization, installed-only language choices, onboarding, permission recovery, automatic PNG/MP4 saving, and local-only translation remain available.

## Validation and limitations

The build-9 release configuration passed 81 executed tests (78 Swift Testing and 3 XCTest); three opt-ins were skipped: installed catalog, installed translation models, and foreground WindowServer lookup. Repository checks passed 49 index and 49 shell assertions. These are automated checks, not complete runtime acceptance.

The Release build and strict Developer ID app-signature verification passed. The exact DMG passed image verification, read-only inspection, full app-bundle byte comparison, version/icon/privacy metadata checks, MIT license comparison, and the Applications-link check. Size: 3,264,442 bytes. SHA-256: `fd2b411334d5e6b7e9f7fb4e10295340ca7b17fbed22264330dab6920a47fbec`. These local artifact checks do not establish clean-Mac installation or GitHub Actions success.

Prior build-8 macOS observations exercised header controls while locked, a header-free PNG export, and a finalized silent MP4. The final OCR grouping refinement passed a real-Vision regression but still needs a complete desktop visual rerun. The input fixture's negative control was inconclusive: native click/drag/scroll routing, keyboard-focus retention, and absence of double input are **not verified**. Do not interpret panel unit tests as proof of those behaviors.

Clean-machine installation/Gatekeeper acceptance, actual administrator-password input, multi-display movement, offline/download recovery, 30-minute stability, translation-quality scoring, and end-to-end latency remain incomplete. This is a testing prerelease, not a stable-release guarantee. Screen exports include underlying screen content; review them before sharing.

This release replaces the beta.1/beta.2 downloads and consolidates `main` into one release baseline. Existing clones must reconcile the rewritten history; preserve local work before switching to the new baseline. Old release notes remain as historical evidence, not current download instructions. No notarization or App Store submission was performed.
