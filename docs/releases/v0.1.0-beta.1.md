# Lens 0.1.0-beta.1 — Development Preview

> Historical record: download assets and tag retired. Use [beta.3](v0.1.0-beta.3.md) for current installation and validation information.

The first downloadable preview of Lens, a local screen-translation overlay for Mac.

## Requirements and download

- Apple Silicon Mac, macOS 26.4 or later.
- Download the `DEVELOPMENT-NOT-NOTARIZED.zip` asset and its `.sha256` checksum. The ZIP contains `Lens.app` and the MIT license.
- This is a **Release-configuration build with an ad-hoc signature**, not a Developer ID signed or notarized distribution. Gatekeeper may block downloaded copies. Do not disable macOS security protections; developers can build from source with Xcode 26.4 or later instead.
- App version 0.1.0, build 2, channel beta.1; development bundle identifier `dev.local.lens`.

## Included

- Resizable screen-translation lens, reproduced-background and transparent modes, click-through, and full-text reader.
- Apple Translation language catalog, installed-pair preparation, and supported macOS preferred-language target selection.
- Independent native settings, lens toolbar, PNG capture, and silent MP4 recording.
- A new blue glass icon showing **A → 가** to make translation recognizable.
- MIT license, privacy documentation, source build instructions, and guarded CI/build/package tooling.

Screen Recording permission is required for capture. Initial language-pack preparation requires internet access. The app interface is currently Korean; translation-language support is determined by Apple Translation and Vision, not every macOS interface language.

## Validation and limitations

Local checks on Apple Silicon with Xcode 26.6 passed: 39 tests, one installed-language test skipped, and 47 shell regression assertions (mocked process/signature metadata). The Release build succeeded; its AppIcon metadata and compiled icon, version/build/channel, privacy manifest, ad-hoc signature validity, ZIP license, and SHA-256 checksum were checked. This does not establish Developer ID signing or notarization. GitHub Actions records checks against the source revision. Installed-language tests are opt-in and are not part of the default suite.

Some translation has been observed during development. Formal clean-install acceptance, offline/download recovery, multiple displays, 30-minute stability, broad translation-quality evaluation, and end-to-end latency targets remain unverified. This is a development preview, not a claim that those release gates are complete.
