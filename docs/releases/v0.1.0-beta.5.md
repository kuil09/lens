# Lens 0.1.0-beta.5 — Notarized Preview

App 0.1.0, build 11. Requires Apple Silicon and macOS 26.4 or later.

## Download and install

- Download `Lens-0.1.0-beta.5-11.dmg` and its `.sha256` sidecar from this release.
- Quit Lens, open the DMG, drag **Lens** into **Applications**, and then open Lens from Applications.
- Both the app and DMG are **Developer ID signed, Apple-notarized, and stapled**. Local Gatekeeper assessments report `accepted`, `source=Notarized Developer ID`. This is not App Store submission.
- The signer and `dev.local.lens` identity are unchanged. No automatic update or settings migration is performed. macOS can still request a normal first-download confirmation or screen-recording permission; do not disable security protections.

```sh
shasum -a 256 -c Lens-0.1.0-beta.5-11.dmg.sha256
```

SHA-256 after stapling: `10a83adc9e712a85c2ce82892f7482933bf8de7cdc7cfca69958c16ad3264ba0`.

## Changes

- Redesigned Finder installer: large aligned app/folder icons, directional arrow, and English/Korean/Japanese installation guidance.
- Corrected Retina artwork scaling and footer clipping through actual Finder inspection.
- Prevent installer tooling from adding Finder attributes that invalidate the signed app. The app inside the finished DMG is strictly verified, not only the prepackaged app.
- Retain beta.4 capture feedback, shared save-folder access, translation, click-through controls, and permission-recovery behavior. No application logic changed in build 11.

## Verification and remaining limits

The Release build, strict app/DMG signatures, Apple acceptance, stapled tickets, and local Gatekeeper assessments passed. The compressed image and checksum validate; the mounted app matches the source build, the license matches the repository, and the Applications link points to `/Applications`. Actual Finder inspection confirmed the final installer layout. See [installer evidence](https://github.com/kuil09/lens/blob/v0.1.0-beta.5/docs/dmg-installer.md).

Packaging checks passed 49 repository-index assertions, 49 shell regressions, and 4 installer-settings tests. The unchanged application implementation retains the separate build-10 record of 101 executed tests with three opt-in tests skipped; those were not rerun for this packaging-only change.

Clean-Mac installation, build-11 first launch from a quarantined browser download, full accessibility, physical click-through, multi-display/Spaces, sustained use, translation quality, and performance acceptance remain incomplete. Notarization does not establish those outcomes. Existing beta.4 installations/downloads remain unnotarized; only this new artifact receives the above acceptance.
