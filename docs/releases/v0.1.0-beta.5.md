# Lens 0.1.0-beta.5 — build 15 update

Requires Apple Silicon and macOS 26.4 or later. This update replaces the build-12 download under the same beta.5 release. Builds 13 and 14 were local previews, not public releases.

## Download and install

- Download `Lens-0.1.0-beta.5-15.dmg` and its `.sha256` sidecar.
- Quit Lens, open the DMG, drag Lens into Applications, and replace the previous copy.
- The app and DMG are Developer ID signed, Apple-notarized, and stapled. Gatekeeper accepts both as Notarized Developer ID. No security bypass is required.
- The signer and `dev.local.lens` identity are unchanged. Saved language choices and the shared save folder remain in place. A normal first-download confirmation or OS-controlled permission prompt may still occur.

```sh
shasum -a 256 -c Lens-0.1.0-beta.5-15.dmg.sha256
```

SHA-256: `4eb609fa06a03220d31a6e7f463f040a3fbe58af7d866196448ad8f6b9f0e8ac`.

## Changes

- **Source-language filtering:** selecting a source now excludes paragraphs detected as another language. Ambiguous/conflicting text stays original. Auto detection groups requests by detected language and skips the target language.
- **Stable reading:** Full Translation keeps a fixed snapshot instead of changing while you read. Use Apply New Translations to update it; unchanged paragraphs retain their views and reading position. Previous-screen and pending translations are labeled.
- **Truncated-text popovers:** with body click-through off, click a truncated translation to read/copy its full result. Shift-Command-T focuses the first truncated item. Changes to the source, movement, hiding, or enabling click-through dismiss the popover.
- **Rounded resize controls:** four narrow exterior input strips retain resizing while body click-through is on. Continuous curved corner markers are clearer on light/dark backgrounds. The toolbar stays interactive; these controls are not added to PNG/video composition.
- Retain build-12 launch/readiness fixes, installed-language choices, save-folder behavior, and security handoff. Restoring a window does not automatically resume capture/recording.
