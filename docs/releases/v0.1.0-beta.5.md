# Lens 0.1.0-beta.5 — build 12 update

Requires Apple Silicon and macOS 26.4 or later. This update replaces the earlier build-11 download under the same beta.5 release.

## Download and install

- Download `Lens-0.1.0-beta.5-12.dmg` and its `.sha256` sidecar.
- Quit Lens, open the DMG, drag Lens into Applications, and replace the previous copy.
- The app and DMG are Developer ID signed, Apple-notarized, and stapled. Gatekeeper accepts both as Notarized Developer ID. No security bypass is required.
- The signer and `dev.local.lens` identity are unchanged. Saved language choices and the shared save folder remain in place. A normal first-download confirmation or OS-controlled permission prompt may still occur.

```sh
shasum -a 256 -c Lens-0.1.0-beta.5-12.dmg.sha256
```

SHA-256: `c3276a6d82164d73f1cdc0b3af1906a1d0467ba5d702ac2ee9359fc733962af9`.

## Fixes

- After completed onboarding, ordinary relaunch/reopening shows the paused lens instead of repeating the setup/recovery guide. Translation and recording do not start automatically.
- Returning from Finder no longer starts an unnecessary full language check. Checking, installed, missing, and failed states are distinct, so a pending check does not open the download guide.
- Explicit start requests wait once for a current check and can be canceled. Closing, pausing, changing languages, or entering System Settings cancels pending starts.
- Language-check failures preserve selections and allow retry. System Settings recovery still hides the overlay and returns through a normal, noncapturing guide.
- Include previously source-only system-language-download guidance and explicit-source request forwarding. Explicit source is a translation hint, not an exclusion filter for text in other languages.

## Verification and limits

GitHub checks/tests/build/development-DMG upload passed. Local tests covered launch routing, delayed language readiness, one-shot start/cancel, stale catalog results, recording and exports. Installed Apple models translated synthetic samples in all six English/Korean/Japanese directions.

Actual macOS checks included three paused relaunches, Finder return and translation start, translation-reader output, click-through header capture/record controls, valid PNG and silent H.264 MP4 saves, and System Settings handoff with explicit resumption. The exact notarized DMG was installed and these key flows rechecked before publication.

Notarization used the authorized local Keychain fallback: CI signing still lacks two Apple authentication secrets. Do not interpret development CI success as CI notarization success.

Clean-Mac installation, actual revoked permissions/missing packs, administrator password entry, external displays, sustained use, full VoiceOver support and controlled visual translation-quality evaluation remain unverified. No existing permission or language installation was reset. See [build-12 validation](https://github.com/kuil09/lens/blob/v0.1.0-beta.5/docs/releases/build-12-validation.md).
