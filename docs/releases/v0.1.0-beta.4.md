# Lens 0.1.0-beta.4 — Local Development Package

App 0.1.0, build 10. Requires Apple Silicon and macOS 26.4 or later.

This revision produces a local DMG and consolidates the source history. It does **not** create or replace a GitHub release. The published beta.3/build 9 DMG and its tag remain unchanged; binaries are excluded from Git.

## Package and install

- `Lens-0.1.0-beta.4-10-DEVELOPMENT-NOT-NOTARIZED.dmg` and its SHA-256 sidecar are generated under `dist/` with `make package ARGS='--development --format dmg'` after `make build`.
- Quit Lens, open the DMG, and drag **Lens** to **Applications**. The image includes the MIT license and an Applications shortcut.
- The app uses the existing Developer ID signer and hardened runtime, with bundle identifier `dev.local.lens`. User language/save-folder settings are preserved; retained macOS screen-recording consent is not guaranteed.
- This preview is **not notarized**. Gatekeeper may block downloaded copies. Do not disable security protections; building from source remains an alternative.

```sh
shasum -a 256 -c Lens-0.1.0-beta.4-10-DEVELOPMENT-NOT-NOTARIZED.dmg.sha256
```

## Changes

- Actual PNG save success changes the header camera to a localized checkmark for 1.5 seconds, independently of recording and subsequent capture attempts.
- The toolbar and menus open the currently configured shared save folder. Narrow windows keep stop/unlock controls and move optional actions into native overflow.
- Explicit Lens return, paired-window minimization, auxiliary-window reopening and language-readiness guidance are improved. Security handoff still hides both panels and does not automatically resume capture on return.
